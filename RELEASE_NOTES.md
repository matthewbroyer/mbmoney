# Release notes · mbmoney.online

## 1.4 · 2026-10-14
- On computers, the search box, backup status and logo spacing now look exactly like the other mb apps: same size, same "Search…" text and the same "/" shortcut.
- The top bar now looks and works the same as in the other mb apps: Search, Data and the light/dark switch sit in the same places with the same icons. On phones they are square icon buttons next to the logo.
- Transactions on phones: the Select all box and the Date / Description / Amount sort buttons sit in one tidy row that lines up with your transactions and stays under the top bar while you scroll.
- The sort buttons on Transactions can now be used with the keyboard (Tab, then Enter).
- Your data, backups and settings are unchanged.

## 1.3 · 2026-10-14
- About card at the bottom of Settings: version, release date, links and copyright in one place.
- Installing from matthewbroyer.com: the hub's Install button opens the app with a short install prompt.
- New "page not found" page that matches the app and links back to it.
- The Install card moved to the bottom of Settings, just above the About card.

Earlier releases (ALPHA, April 2024 through BETA 4.7, October 13, 2026) are listed in the app under Settings → Release notes. The "Official Web App" brand line read v1.1 at BETA 4.6 and v1.2 at BETA 4.7.
